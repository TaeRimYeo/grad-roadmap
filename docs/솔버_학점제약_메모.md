# 학기별 학점 제약 — 솔버 구현 메모

> 5주차 `solver.py` 작성 시 이 문서를 Claude Code 에 함께 전달할 것

## 규칙

| 구분 | 최소 | 최대 |
|---|---|---|
| 중간 학기 | 15학점 | 22학점 |
| **마지막 학기** | **10학점** | 22학점 |

**마지막 학기는 고정된 학기 번호가 아니다.** 해당 학생이 실제로 졸업하는 학기이며,
전과·휴학 등으로 학생마다 다르다. 즉 **솔버가 결정하는 값**이다.

## 왜 단순 제약으로 안 되는가

"6학기가 마지막"이라고 고정하면, 5학기에 졸업하는 학생의 5학기 하한이
15학점으로 잘못 적용된다. 마지막 학기 여부 자체가 해에 의존하므로
**조건부 제약(reified constraint)** 이 필요하다.

## CP-SAT 구현

### 변수

```python
L[t]      = 학기 t 의 총 학점 (IntVar)
used[t]   = 학기 t 를 사용하면 1 (BoolVar)
last[t]   = 학기 t 가 마지막 학기이면 1 (BoolVar)
```

### 제약

```python
# 1. 학기는 연속 사용 (중간에 비는 학기 없음)
for t in range(1, T_MAX):
    model.Add(used[t] >= used[t+1])

# 2. 마지막 학기 정의 : 쓰고 있고, 다음 학기는 안 씀
for t in range(1, T_MAX+1):
    nxt = used[t+1] if t < T_MAX else 0
    model.AddBoolAnd([used[t], nxt.Not()]).OnlyEnforceIf(last[t])
    # 또는 last[t] == used[t] - used[t+1] 로 선형 표현 가능

# 3. 마지막 학기는 정확히 하나
model.Add(sum(last[t] for t in terms) == 1)

# 4. 학점 상한 (항상)
for t in terms:
    model.Add(L[t] <= 22)

# 5. 미사용 학기는 0학점
for t in terms:
    model.Add(L[t] == 0).OnlyEnforceIf(used[t].Not())

# 6. 중간 학기 하한 15
for t in terms:
    model.Add(L[t] >= 15).OnlyEnforceIf([used[t], last[t].Not()])

# 7. 마지막 학기 하한 10
for t in terms:
    model.Add(L[t] >= 10).OnlyEnforceIf(last[t])
```

### 선형 대안 (더 단순)

`last[t] = used[t] - used[t+1]` 로 두면 조건부 없이도 표현 가능하다.

```python
# L[t] >= 15·used[t] - 5·last[t]
#   중간 학기(used=1, last=0) → L >= 15
#   마지막 학기(used=1, last=1) → L >= 10
#   미사용(used=0, last=0)     → L >= 0
for t in terms:
    model.Add(L[t] >= 15*used[t] - 5*last[t])
    model.Add(L[t] <= 22*used[t])
```

이쪽이 제약 수가 적어 성능이 좋다. 먼저 이 형태로 구현할 것.

## 목적함수와의 관계

```
minimize sum(used[t])      # 졸업 학기 수 최소화
```

`max(pos[c])` 대신 `sum(used[t])` 를 쓰면 위 변수를 그대로 재사용할 수 있다.

## 검산

졸업요건 110학점 기준, 학기 수별 이수 가능 범위:

| 학기 수 | 최소 | 최대 | 110학점 |
|---|---|---|---|
| 4 | 55 | 88 | 불가 |
| **5** | 70 | **110** | **가능 (빠듯)** |
| 6 | 85 | 132 | 가능 |
| 7 | 100 | 154 | 가능 |
| 8 | 115 | 176 | 불가 (최소 초과) |

- **이론상 최단 졸업은 5학기.** 단 5학기 전부 22학점을 채워야 함
- **8학기부터는 불가능.** 최소 이수량(115)이 졸업요건(110)을 넘어섬
  → 초과학기 학생은 이 하한 규칙의 예외가 있는지 학과 확인 필요
