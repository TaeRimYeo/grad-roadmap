# 학기별 학점 제약 — 솔버 구현 메모

> 5주차 `solver.py` 작성 시 이 문서를 Claude Code 에 함께 전달할 것

## 규칙 (학교 규정 확정)

| 대상 | 학기 | 최소 | 최대 |
|---|---|---|---|
| 전문학사 · 중간 학기 | 1~6학기 | 15 | 22 |
| 전문학사 · **본인의 마지막 학기** | 학생마다 다름 | **10** | 22 |
| 전문학사 · **초과학기** (졸업유예 등) | 7학기~ | **10** | 22 |
| **전공심화** (4학년) | 2학기 | 개설 과목 전부 이수 | — |

- **마지막 학기는 고정된 번호가 아니다.** 해당 학생이 실제로 졸업하는 학기이며 솔버가 결정한다
- 초과학기는 졸업 학년을 지났으므로 모든 학기가 10~22
- 전공심화는 고를 과목이 없으므로 **솔버를 쓰지 않는다.** 진단(남은 과목 표시)만 한다

## 변수

```python
L[t]    = 학기 t 의 총 학점 (IntVar)
used[t] = 학기 t 를 사용하면 1 (BoolVar)
last[t] = 학기 t 가 마지막 학기이면 1
```

## 제약 (선형식 — 조건부 제약 없이 한 번에 처리)

```python
T_MAX = 8   # 정규 6 + 초과 2 까지 탐색

# 학기는 연속 사용
for t in range(1, T_MAX):
    model.Add(used[t] >= used[t+1])

# 마지막 학기 = 이번 학기는 쓰고 다음 학기는 안 씀
for t in range(1, T_MAX+1):
    nxt = used[t+1] if t < T_MAX else 0
    model.Add(last[t] == used[t] - nxt)

# 상한 (전 학기 공통)
for t in terms:
    model.Add(L[t] <= 22 * used[t])

# 하한
for t in terms:
    if t <= 6:
        # 중간 학기 15, 마지막 학기 10, 미사용 0
        model.Add(L[t] >= 15 * used[t] - 5 * last[t])
    else:
        # 초과학기는 마지막이든 아니든 10
        model.Add(L[t] >= 10 * used[t])
```

| 경우 | used | last | 하한 |
|---|---|---|---|
| 정규 중간 학기 | 1 | 0 | 15 |
| 정규 마지막 학기 | 1 | 1 | 10 |
| 초과학기 | 1 | 0/1 | 10 |
| 미사용 | 0 | 0 | 0 |

## 목적함수

```python
minimize sum(used[t])     # 졸업 학기 수 최소화
```

6학기 이내에 해가 있으면 자연스럽게 그쪽이 선택된다. 별도의 2단계 풀이는 필요 없다.

## 화면 처리

- 7학기 이상이 배치되면 해당 학기 카드에 **경고색 테두리 + "초과학기" 라벨**
- 상단 배너: "정규 학기 안에 졸업이 어려워요 · N학기 추가 필요"
- 8학기로도 해가 없으면 '졸업 불가' 화면(원인 설명)으로

## 검산 — 하한 때문에 막히는 경우는 없는가

처음부터 전부 계획한다고 가정한 극단적 경우:

| 학기 수 | 최소 이수 | 최대 이수 | 110학점 |
|---|---|---|---|
| 5 | 70 | 110 | 가능 |
| 6 | 85 | 132 | 가능 |
| 7 | 100 | 154 | 가능 |
| 8 | 110 | 176 | 가능 |

실제로는 **이미 이수한 학기는 계획에서 빠지고 남은 학기만 푼다.** 남은 학점이 하한보다 적으면
(예: 3학점만 남았는데 마지막 학기 최소 10학점) 솔버가 **전공선택이나 교양 자리를 추가로 넣어 10학점을 채운다.**
선택 과목과 가상 과목이 충분하므로 하한 때문에 해가 없어지는 경우는 발생하지 않는다.
