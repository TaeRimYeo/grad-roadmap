# frontend — 학기 로드맵

React 19 · TypeScript · Vite · Tailwind CSS v4 · lucide-react

## 실행

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:5173 → 12개 화면 시안이 나온다.

같은 와이파이의 휴대폰에서 보려면 터미널에 표시되는 `Network: http://192.168.x.x:5173` 주소로 접속.
